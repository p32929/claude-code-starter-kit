What is in it

10 subagents

bug-hunter finds the root cause instead of the symptom — it reproduces first, then traces the bad value back to where it first went wrong. code-reviewer reports real defects and skips style opinions. test-writer matches the framework you already use, runs the suite and pastes the real output. Plus refactorer, api-designer, sql-tuner, perf-profiler, dependency-auditor, migration-planner, docs-writer.

12 slash commands

/commit/pr/review/debug/fix-ci/tests/security/cleanup/explain/scaffold/onboard/changelog

They read your real diff before they act. /commit matches your repo's existing message style and refuses to commit a secret. /review greps for every caller of every changed signature — the check human reviewers always skip.

7 hooks — the part that can actually stop Claude

Hooks are the only piece of Claude Code that can block an action rather than politely ask.

  • typecheck-on-edit — runs tsc --noEmit / mypy / go build / cargo check after every edit and feeds the errors straight back to Claude so it fixes them in the same turn. The highest-value file in the pack.
  • guard-destructive — blocks rm -rf /, git reset --hard, git clean -fd, force-push to main, DROP TABLE, DELETE with no WHERE, terraform destroy, fork bombs.
  • guard-secrets — refuses to read or write .env, id_rsa, *.pem, .aws/credentials.
  • format-on-edit — 10 languages: biome, prettier, ruff, black, gofmt, rustfmt, rubocop, shfmt, dart, swiftformat.
  • plus protect-main, log-session, notify-done.

Every hook in this pack was executed against real hook payloads before it shipped — that testing found and fixed two genuine bugs. The docs give you the exact commands to verify it yourself in two minutes:

printf '{"tool_input":{"command":"rm -rf /"}}' | ./guard-destructive.sh; echo $?
# 2 = blocked, 0 = allowed

4 skills

ship-it — the full pre-merge gate (build, typecheck, tests, review, security, leftovers, migration safety) that stops at the first blocker. incident-triage — production is down right now: stop the bleeding, then root-cause. spec-to-plan. legacy-rescue — writes characterisation tests before you touch untested legacy code, so you can tell a fix from a regression.

6 CLAUDE.md templates

Universal · Next.js + TypeScript · Python + FastAPI · Node API · Flutter · Monorepo. Each one with a commands table and a real Gotchas section.

Install

unzip claude-code-drop-in-kit.zip
cd claude-code-drop-in-kit
bash install.sh            # this project
bash install.sh --global   # ~/.claude, every project

Then restart Claude Code. Requirements: Claude Code, bash, git, python3. Windows works under WSL.
